# Поиск автозапчастей и аналогов

Клиентское приложение на React и Redux для поиска автозапчастей через [API Favorit Parts](https://lk.favorit-parts.ru/static/wsprice.pdf). Подбор идёт в два этапа: сначала артикул и производитель, затем таблица с деталью и её аналогами.

## Запуск

Нужен Node.js 20.19 или новее, а в ветке 22 версия 22.12 или новее. Я проверяла на Node.js 24.

```bash
npm install
cp .env.example .env
npm run dev
```

Откройте адрес, который покажет Vite, обычно `http://localhost:5173`.

В `.env.example` указан демо-ключ из документации API. Чтобы работать со своим ключом, замените значение `VITE_FAVORIT_API_KEY` в файле `.env` и перезапустите приложение.

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Публикация на GitHub Pages

Сайт собирается и публикуется сам при каждом push в ветку `main`. За это отвечает `.github/workflows/deploy.yml`.

Перед первым запуском откройте в репозитории Settings, затем Pages, и в поле Source выберите GitHub Actions. Ход сборки виден на вкладке Actions. Сайт откроется по адресу `https://favorit-parts.github.io/`.

На сайте работает демо-ключ из `.env.example`. Чтобы использовать другой ключ, замените его в этом файле, но учтите, что файл попадает в репозиторий.

## Как пользоваться

1. Введите артикул в поле «Артикул детали». Поиск запускается сам через полсекунды после ввода, если введено от 3 символов.
2. Выберите производителя в появившемся списке.
3. Посмотрите таблицу. В ней указаны производитель, артикул, название, цена и остаток.
4. Нажмите «Склады» в нужной строке, чтобы увидеть цену, остаток и дату отгрузки на каждом складе.
5. Если строк много, нажмите «Показать ещё» под таблицей.

### Как читать таблицу

- Искомая деталь стоит первой и отмечена меткой «Искомая». Аналоги идут от дешёвых к дорогим.
- «от 129,52 ₽» значит, что предложений несколько и это самая низкая цена среди них.
- Прочерк вместо цены значит, что на складах нет предложений. Такие позиции стоят в конце таблицы.
- Дата отгрузки показана по московскому времени. Время рядом с датой означает, до какого часа нужно заказать, чтобы товар отгрузили в этот день.

### Сообщения и ошибки

| Что видно | Что это значит | Что делать |
| --- | --- | --- |
| Индикатор загрузки | Запрос выполняется | Подождать |
| «По артикулу ... ничего не найдено» | Такой детали нет в базе | Проверить артикул |
| «Не удалось связаться с сервером» | Нет сети или запрос не прошёл | Проверить интернет и нажать «Повторить» |
| «Сервер долго не отвечает» | Нет ответа за 20 секунд | Нажать «Повторить» |
| «Сервер вернул некорректный ответ» | Сервер прислал ошибку или не JSON | Нажать «Повторить» |
| «Неверный ключ API» или «Не задан ключ API» | Ключ неверный или его нет | Проверить `.env` и перезапустить приложение |
| «Превышен лимит запросов» | Исчерпан лимит API | Повторить позже |

## Артикулы для проверки

Данные в API живые, поэтому количество может со временем измениться.

| Артикул | Что выбрать | Что проверить |
| --- | --- | --- |
| `0189` | `NGK/NTK` | 4 производителя, у выбранного 24 аналога, в названии бренда есть `/` |
| `7160500039S` | `MEYLE` | 741 аналог, кнопка «Показать ещё», раскрытие складов |
| `01089` | `Meat & Doria` | 10 вариантов в списке, в названии бренда есть `&`, аналогов 0 |
| `7260500039S` | ничего | деталь не найдена, появится сообщение «ничего не найдено» |
| `01` | ничего | меньше 3 символов, запрос не отправляется |

## Решения

- **Цена.** Документация просит не использовать поле `price` у товара, поэтому цена берётся из складов.
- **Длинные списки.** У одной детали бывает больше 700 аналогов, поэтому таблица показывает по 50 строк.
- **Устаревшие ответы.** Если пользователь успел начать новый поиск, ответ на старый запрос игнорируется.
- **Ошибки API.** API сообщает об ошибке и с кодом 200, и с кодом 403, а для ненайденной детали возвращает запись с пустыми полями. Всё это обрабатывается в `src/api.js`.

## Структура

```
src/
  api.js                     запросы к API и разбор ответов
  store.js                   Redux: состояние поиска и запросы
  App.jsx                    страница
  components/
    SearchForm.jsx           поле ввода артикула
    BrandList.jsx            этап 1: список производителей
    OffersTable.jsx          этап 2: таблица аналогов и складов
    Status.jsx               лоадер и сообщение об ошибке
```

## Ключ API

Ключ попадает в клиентскую сборку, и его можно увидеть в браузере. Для демо-ключа это не проблема, но в рабочем проекте запросы лучше проводить через свой сервер.
